NO Report Monitoring

💡 Tips
📂 Upload a CSV File
Drag & drop your AppSheet export onto the upload zone, or click to browse. Only .csv files are accepted.
📋 Required CSV Columns
Your CSV must contain these four columns:
  • AREA MANAGER
  • SUPERVISOR
  • REFILLER NAME
  • Category
Column names are matched case-insensitively.
🔍 How Records Are Filtered
Only rows where Category = "NO Report" are shown. All other rows (PRESENT, ABSENT, DAY OFF, etc.) are counted for PJP ratio but not displayed.
🔢 PJP Ratio Explained
PJP = Planned Journey Plan. The ratio shows NO Reports ÷ Total PJP visits.

🟢 Low — under 25%
🟠 Moderate — 25–49%
🔴 High — 50% or more

Toggle it on/off using the Show PJP Ratio button in the AM Breakdown panel.
🖼️ Exporting Card Images
Each report card can be copied to clipboard or downloaded as a PNG.

📋 Copy Image — pastes directly into Viber, Teams, etc.
⬇️ Download PNG — saves to your Downloads folder.

Use Download All Images to batch-export every card at once.
🔎 Search & Filter Cards
Type any name in the search box to filter cards by:
  • Area Manager name
  • Supervisor name
  • Refiller name
The card count updates in real time.

❓ How This Program Works

1

Export Your AppSheet Data

From AppSheet, export the PJP view data as a CSV (e.g. AppSheet_ViewData_YYYY-MM-DD.csv). This file contains one row per refiller per planned store visit for the day.

2

Upload the CSV Here

Drag & drop the file onto the upload zone or click to browse. The tool reads these key columns from your export:

AREA MANAGERSupervisor's AM
SUPERVISORField supervisor
REFILLER NAMERefiller on PJP
CategoryVisit outcome tag
STORE NAMEOutlet visited
REGION / OMHierarchy info
3

Understanding Categories

Each row is tagged with a Category based on what happened during that store visit:

NO Report ⚠️ PRESENT ✅ Time In with PRESENT Time In Only ABSENT DAY OFF VACANT

This tool only surfaces NO Report rows — refillers who were scheduled but did not submit any attendance record.

4

Review the AM Breakdown Panel

After processing, the Breakdown by Area Manager panel groups all NO Report refillers by their AM and supervisor. Expand each AM row to see per-supervisor counts and progress bars.

5

Use the PJP Ratio to Spot Issues

Click Show PJP Ratio to reveal what percentage of each supervisor's planned visits ended up as NO Reports. A high ratio (🔴 red) may indicate a field attendance problem that needs follow-up.

6

Share Report Cards

Each supervisor gets a Report Card listing their NO Report refillers. Copy or download these cards as PNG images to send directly via Viber, Teams, or group chats — no screenshots needed.

Data source: AppSheet PJP View Export  ·  Filters on Category = "NO Report"

amber = date parsed but an assumption was made (year/century) red = could not be parsed as a date

How ambiguous dates are handled: weekday names/prefixes (Thu, Thursday) and clock times are stripped before parsing. All-numeric slash/dot dates use the 4-digit year (or year-like part) to anchor the format, then decide month-vs-day order by magnitude — if one part is >12 it's treated as the day; when genuinely ambiguous (e.g. 3/14/24) it defaults to month/day (US convention), while dot-separated dates (e.g. 14.03.2024) default to day.month (European convention). 2-digit years use the standard pivot: 00–68 → 2000s, 69–99 → 1900s. Values missing a year (e.g. Mar 14) assume the current year and are flagged amber. Values with a month+year but no day (e.g. Mar-24), weekday-only text, blank cells, or unrecognized text are flagged red as invalid — a specific day can't be inferred. Excel serial date numbers (e.g. 45365) pasted from a cell that lost its date formatting are also detected and converted automatically.
